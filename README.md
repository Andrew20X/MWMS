# Measuresoft Workforce Management System (MWMS)

MWMS is an enterprise attendance and workforce management system developed for Measuresoft Oil Services.

## Technology Stack

- ASP.NET Core 8 Web API
- Entity Framework Core
- SQL Server
- React.js
- JWT Authentication
- Clean Architecture

## Features

- Authentication
- Employee Management
- Attendance Management
- Fingerprint Device Integration
- Leave Management
- Permission Requests
- Attendance Corrections
- Reports
- Notifications
