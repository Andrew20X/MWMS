# Project Master Prompt

## Project Title

**Measuresoft Workforce Management System (MWMS)**

## Project Overview

I am building a real-world enterprise web application for **Measuresoft Oil Services**. This is **not** a university CRUD project. The system is intended to replace the company's current Excel-based attendance and timesheet process with a fully automated workforce management system.

The project should be designed using enterprise software engineering principles, clean architecture, scalability, maintainability, and security.

---

# Current Workflow

Currently, the company uses:

* Fingerprint attendance devices (ZKTeco devices communicating over TCP/IP, usually on port 4370).
* Attendance logs collected from fingerprint devices.
* Monthly Excel Timesheets.
* Employees manually fill attendance information.
* HR manually reviews and calculates attendance.

Problems:

* Manual data entry
* Human errors
* Time consuming
* Difficult reporting
* No dashboards
* No approval workflow
* No centralized data

---

# Proposed Solution

Build a complete web application that automates the entire attendance process.

The system should:

* Read attendance logs from fingerprint devices.
* Store raw logs.
* Process attendance automatically.
* Calculate working hours.
* Calculate lateness.
* Calculate overtime.
* Calculate early leave.
* Detect missing check-in/check-out.
* Generate monthly timesheets automatically.
* Export Excel files matching the company's current format.
* Provide dashboards for Employees, Managers, HR, and Admin.

The Excel file should become an **output** of the system instead of the primary data source.

Fingerprint devices communicate using TCP/IP.

Typical configuration:

* Device IP
* Device Port (4370)
* Device Timeout

The system should:

* Connect to fingerprint devices.
* Synchronize attendance logs.
* Store raw logs.
* Process attendance automatically.

# Database Philosophy

The database is the single source of truth.

Excel files are generated from database data.

Raw fingerprint logs must never be modified.

Attendance should always be calculated from raw logs.
